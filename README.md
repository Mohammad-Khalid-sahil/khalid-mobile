# موبایل خالد — Khalid Mobile v2

سیستم کامل مدیریت فروشگاه موبایل و لوازم جانبی (دری · پښتو · English، RTL/LTR، تقویم شمسی + میلادی، افغانی).
Full mobile-shop management system: phones tracked by IMEI, stock, purchases, sales/POS, returns & exchanges,
customer & supplier ledgers, cashbox & accounts, expenses, employees & salaries, warranty, repairs, reports, backups, audit log.

**Stack:** React 18 + Vite + Tailwind 4 (client) · Node/Express + MongoDB/Mongoose (server) · JWT auth.

## راه‌اندازی سریع / Quick start

نیازمندی‌ها: Node.js 18+ و MongoDB (محلی یا Atlas).

```bash
npm run install:all                 # نصب هر دو بخش
cp server/.env.example server/.env  # و JWT_SECRET را عوض کنید
npm run seed                        # (اختیاری) داده‌های نمونه — دیتابیس را پاک می‌کند!
npm run dev:server                  # ترمینال ۱ → http://localhost:5000
npm run dev:client                  # ترمینال ۲ → http://localhost:5173
```

بدون seed، در اولین اجرا کاربر `admin` / رمز `admin123` ساخته می‌شود و **باید** رمز را عوض کنید.
با seed: `admin/admin123`، `ali/ali12345` (فروشنده)، `sara/sara1234` (حسابدار).

### استفاده در دکان (یک پورت)
```bash
npm run build && npm start          # سرور، فرانت ساخته‌شده را هم سرو می‌کند → http://localhost:5000
```
پشت HTTPS/Proxy: `TRUST_PROXY=1` بگذارید. فایل‌های پشتیبان در `server/backups/` (فقط مدیر؛ مجوز فایل ۶۰۰).

## تصمیم‌های بخش ۳۵ سند (پیش‌فرض‌ها — همه قابل تغییرند)
1. یک فروشگاه (مدل داده برای چند شعبه آماده نشده؛ افزودن `branch` بعداً ممکن است).
2. ترمیمات فعال است؛ از تنظیمات خاموش می‌شود. 3. سیم‌کارت/خدمات به‌صورت «کالای خدماتی» بدون موجودی.
4. واحد پول AFN (قابل تغییر؛ چندواحدی نیست). 5. مفاد: تعریف بالا؛ معاش حساب‌شده و پیش‌پرداخت دارایی است تا کسر شود.
8. بارکدخوان (مثل صفحه‌کلید کار می‌کند) و چاپگر حرارتی (چاپ مرورگر، 58/80mm). 9. آنلاین/شبکهٔ محلی (نه آفلاین‌مستقل).
13. خرید از مشتری (گوشی دست‌دوم) در «خرید جدید ← خرید از مشتری». 14. حساب بانکی/انتقال/دیجیتال پشتیبانی می‌شود.

cd server && MONGO_URI=mongodb://127.0.0.1:27017 npm test    # ۱۲ سناریوی کامل قوانین مالی/موجودی (از دیتابیس جدا استفاده می‌کند)

## نکات
* تراکنش چندسندی MongoDB لازم نیست (replica set نیاز نیست): هر عملیات چندمرحله‌ای در صورت خطا خودکار برگردانده می‌شود.
* رمزها با bcrypt؛ ورود با محدودیت تعداد تلاش؛ اعتبارسنجی سمت سرور؛ هدرهای امنیتی (helmet).
* فونت‌ها داخل پروژه‌اند (بدون اینترنت هم درست نمایش می‌دهد).
